What I Built

งาน A1 นี้ หนูได้ทดลองสร้างเว็บไซต์ Learning Portfolio หน้าเดียวค่ะ เพื่อแนะนำตัวเองและบันทึกการเรียนรู้

องค์ประกอบหลัก: มีส่วนแนะนำตัว รายละเอียดโปรเจกต์ ขั้นตอนการพัฒนา และการสะท้อนความคิดค่ะ

การทำงานของ Client / Server: ตอนเปิดไฟล์นี้ผ่านเว็บเบราว์เซอร์ ทำงานแค่ฝั่ง Client (Browser) เท่านั้นค่ะ เพราะอ่านไฟล์ HTML จากในเครื่องคอมพิวเตอร์ตรงๆ ยังไม่ได้ผ่าน Server (ขึ้นต้นด้วย file://)

How I Built It

ขั้นตอนการทำ เริ่มจากลองเขียนโครงสร้างด้วย HTML แล้วใส่ CSS ปรับสีกับจัดระยะห่างนิดหน่อยค่ะ

เครื่องมือที่ใช้:

  • Visual Studio Code สำหรับพิมพ์โค้ด
  • MDN Web Docs เอาไว้เปิดหาคำสั่ง HTML

Reflection

ปัญหาที่เจอและการแก้ไข:
ตอนแรกใส่รูปแล้วรูปไม่ยอมขึ้นหน้าเว็บค่ะ งงอยู่นานมาก พอลองเช็กดูถึงรู้ว่าใส่ชื่อไฟล์ผิด และวางรูปไว้นอกโฟลเดอร์ media พอเปลี่ยนชื่อไฟล์รูปให้ตรงกับในแท็ก <img> แล้วย้ายรูปไปไว้ในโฟลเดอร์ media รูปก็ขึ้นแล้วค่ะ

สิ่งที่เข้าใจมากขึ้น:
เข้าใจวิธีใส่รูปภาพด้วย Relative Path มากขึ้น และรู้ว่าชื่อไฟล์กับนามสกุลไฟล์รูป (.png / .jpg) สำคัญมาก ถ้าพิมพ์ผิดแค่นิดเดียวรูปก็จะไม่ขึ้นเลย

สิ่งที่อยากพัฒนาต่อ:
อยากลองแต่งสีหน้าเว็บให้สวยกว่านี้ และเรียนรู้คำสั่ง CSS ใหม่ๆ เพิ่มเติมค่ะ
